# فريق القمة — حصاد أغسطس 2026

موقع تفاعلي من صفحة واحدة يستعرض مستجدات فريق القمة لشهر أغسطس 2026، مبني بـ React + Vite + Tailwind CSS + Framer Motion.

## هوية بصرية مستخرجة من الشعار

- **الخلفية:** كحلي داكن (`#0A1420` / `#050810`) — نفس عمق خلفية الشعار.
- **الذهبي:** تدرّج `#F3E3B8 → #C89B3C` — من حرف الـ P المعدني في الشعار.
- **الفضي:** تدرّج `#EAF0F5 → #7C8CA0` — من حرف الـ T المعدني في الشعار.
- **الخطوط:** Cairo للعناوين (طابع هندسي حاسم يناسب الطابع التقني)، وIBM Plex Sans Arabic للنصوص (وضوح عالٍ في القراءة على الهاتف).
- **الحركة:** خط ذهبي عمودي (Spine) يمتد بين المستجدات ويُضيء تدريجيًا مع التمرير — استلهام مباشر من الخطوط والعقد الصغيرة في الشعار، وهو العنصر البصري الجريء الوحيد في الصفحة؛ كل ما عداه هادئ ومنضبط.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

## البناء للنشر

```bash
npm run build
```

الناتج يكون في مجلد `dist/` وجاهز لرفعه على أي استضافة ثابتة (Vercel, Netlify, GitHub Pages...).

## هيكلة المشروع

```
src/
  assets/logo.jpg          الشعار المرفق
  components/
    Hero.jsx                الشاشة الافتتاحية
    Intro.jsx                النص التمهيدي
    Updates.jsx              حاوية المستجدات + الخط المضيء
    UpdateCard.jsx            بطاقة مستجد واحد
    Ending.jsx                الخاتمة التشويقية
    Footer.jsx                التذييل
  data/updates.js            محتوى المستجدات الستة (عدّل هنا فقط لتحديث النصوص)
  hooks/useReveal.js         هوك ظهور عند التمرير
```

لتحديث نصوص المستجدات لاحقًا، عدّل ملف `src/data/updates.js` فقط دون لمس بقية المكوّنات.
